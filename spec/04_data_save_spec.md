# データ保存・スコア記録仕様書

## 1. 概要
ユーザーのモチベーション維持や、日々の成果を確認できるようにするため、ゲームクリア時の記録を端末内に保存・記録します。

---

## 2. 保存対象データ
各難易度（レベル1〜3）ごとに、以下のデータを記録します。

1. **ベストクリアタイム（秒）**:
   - ゲーム開始からすべてのペアを揃えるまでにかかった最短時間。
2. **最小タップ回数（回）**:
   - カードを揃えるまでにかかった最も少ないカード選択（タップ）回数。
3. **最新のプレイ日時 / プレイ履歴**:
   - 「今日プレイしたかどうか」を判定するための日付ログ。
   - 日々の継続を可視化するためのデータ。

---

## 3. 保存技術（想定）
- **ローカル保存（Webブラウザ / ローカルストレージ）**:
  - `localStorage` などの技術を使用し、アプリを閉じても記録が消えないように端末内に保存します。
  - アカウント登録などの複雑な手続きなしで、すぐに自分の記録が蓄積されます。
- **リセット機能**:
  - データを最初からやり直したい時のために、設定やスコアを削除・初期化できる「記録を消す」ボタンをわかりやすい場所に設けます。
